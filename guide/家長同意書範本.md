# LINE 定位簽到系統 家長告知暨同意書（範本）

> 本範本僅供參考，請依貴單位實際情況修改；如有疑義請諮詢法律專業人士。

親愛的家長您好：

本班（以下稱「本班」）為掌握學生到班狀況，將使用「LINE 定位簽到系統」。依《個人資料保護法》規定，說明如下：

1. **蒐集目的**：學生出缺席管理、到班安全通知。
2. **蒐集項目**：
   - 學生及家長之 LINE 顯示名稱與 LINE 使用者識別碼
   - 學生姓名、學號、班級
   - 簽到時間、簽到狀態（準時／遲到／請假／未到）
   - 簽到當下與上課地點的**距離（公尺）**及手機回報的定位精度
3. **不蒐集事項**：系統**不保存學生的經緯度位置**，僅在學生按下「簽到」的那一刻讀取一次定位，用來計算是否在上課地點範圍內；不會在背景追蹤學生位置。
4. **利用方式**：學生於上課開始後 ___ 分鐘仍未簽到（且未請假）時，系統將以本班 LINE 官方帳號私訊通知您；若學生之後抵達，會再通知您「已到」。訊息僅發送給與該學生配對之家長，其他家長不會看到。
5. **保存期間**：簽到與通知紀錄保存至本學期結束後 ___ 個月，屆時刪除。
6. **資料存放**：資料存放於本班之 Google 試算表，僅本班授權老師可存取。
7. **您的權利**：您可隨時請求查詢、閱覽、補正、停止利用或刪除您與孩子的資料。若不同意使用本系統，請告知本班，改由老師人工點名。
