# 快速安裝（約 20～30 分鐘，只要會用瀏覽器）

需要：一個 Google 帳號、一個 LINE 官方帳號（免費）。不需要 GitHub，也不用複製貼上程式碼。

## 1. 複製範本試算表（1 分鐘）

點這個連結 →「建立副本」：
https://docs.google.com/spreadsheets/d/1H1N6qZQRWPGXpUKunGQaKYTqXBjCDIFIWqIxhZAxvS4/copy

複製後把「設定」表的「補習班名稱」改成你的班級名稱。

## 2. 部署網頁應用程式（3 分鐘）

1. 在你複製的試算表：「擴充功能 → Apps Script」。
2. 右上「部署 → 新增部署作業」→ 類型「網頁應用程式」→ 執行身分「我」、誰可以存取「所有人」→ 部署。
3. 第一次會要求授權：按「允許」（出現「Google 尚未驗證」時按「進階 → 前往」）。
4. 複製「網頁應用程式網址」（結尾是 `/exec`），等一下要貼。

## 3. 在 LINE 拿兩樣東西（10 分鐘）

1. [LINE Official Account Manager](https://manager.line.biz/) → 你的官方帳號 → 右上「設定」→「Messaging API」→「啟用 Messaging API」，選擇或建立一個 Provider。
2. 同一頁「回應設定」：自動回應訊息「關閉」、Webhook「開啟」。
3. [LINE Developers](https://developers.line.biz/console/) → 該 Provider → Messaging API channel →「Messaging API」分頁最下方「Channel access token」→ Issue → **複製 token**。
4. 同一個 Provider → Create a new channel → **LINE Login** → 建好後在「Basic settings」**複製 Channel ID**。

## 4. 一鍵設定（3 分鐘）

回到試算表，重新整理 → 選單「簽到系統 → ★ 一鍵設定」，依序貼上：

1. Channel access token
2. `/exec` 網址
3. LINE Login Channel ID

精靈會自動設定 Webhook、建立工作表、啟用每分鐘自動檢查，並在「設定」表產生 **LIFF Endpoint URL**。

## 5. 建立 LIFF（5 分鐘）

精靈第 4 步會提示你：

1. LINE Developers → LINE Login channel →「LIFF」→ Add：Size「Full」、Endpoint URL 貼「設定」表的 **LIFF Endpoint URL**、Scopes 勾 `openid`、`profile`、Add friend option「On (Aggressive)」。
2. 把建好的 LIFF URL（`https://liff.line.me/…`）貼回精靈。
3. **把 LINE Login channel 右上角從 Developing 改成 Published**（沒改的話只有你自己打得開）。

精靈最後會列出還沒完成的項目；全部打勾就裝好了。

## 6. 開始使用

1. 「學生」表填學號、姓名、班級；「課表」表每天一列「到校簽到」，填教室經緯度（Google 地圖在教室按右鍵就看得到）。
2. 把官方帳號 QR code 發給學生和家長加好友，在「LINE好友」表填角色與學號。
3. LINE Official Account Manager →「圖文選單」→ 建一個「簽到」按鈕，連結填 LIFF URL。
