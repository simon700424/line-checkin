# 設定教學（從零到可以上線）

預計 1～2 小時。全部免費：Google 試算表 + Apps Script + LINE 官方帳號免費方案。

整體架構：

```
學生手機 LINE ──開啟──▶ LIFF 簽到頁（docs/index.html，放在 GitHub Pages）
                              │ 送出 ID token + GPS
                              ▼
                    Google Apps Script（gas/）◀── 每分鐘觸發：檢查未到
                              │ 讀寫                     │ 推播
                              ▼                          ▼
                     Google 試算表（老師後台）      家長 LINE（官方帳號私訊）
```

---

## 步驟 1：建立試算表與 Apps Script

1. 開一個新的 Google 試算表，命名例如「簽到系統」。
2. 選單「擴充功能 → Apps Script」。
3. 左側「專案設定（齒輪）」→ 勾選「在編輯器中顯示 appsscript.json 資訊清單檔案」。
4. 回到編輯器，把本 repo `gas/` 資料夾裡的檔案逐一建立並貼上內容（檔名相同即可）：
   `Logic.gs`、`Sheets.gs`、`Line.gs`、`Main.gs`、`Notify.gs`、`Setup.gs`、`appsscript.json`
   （預設的 `程式碼.gs` 可以刪掉）
5. 儲存後回到試算表，重新整理頁面，上方會出現「簽到系統」選單。
6. 點「簽到系統 → 1. 初始化試算表」，第一次會要求授權，按允許。
   完成後會多出：設定、LINE好友、學生、課表、請假、停課、簽到紀錄、通知紀錄 八張工作表。
7. 回到 Apps Script，右上「部署 → 新增部署作業」：
   - 類型：網頁應用程式
   - 執行身分：**我**
   - 誰可以存取：**所有人**
   - 部署後複製「網頁應用程式網址」（結尾是 `/exec`），後面會用到兩次。

> ⚠️ 之後改程式碼時，要用「部署 → 管理部署作業 → 編輯（鉛筆）→ 版本：新版本」，網址才不會變。

## 步驟 2：開啟 LINE 官方帳號的 Messaging API

1. 到 [LINE Official Account Manager](https://manager.line.biz/) → 你的帳號 → 右上「設定」→「Messaging API」→「啟用 Messaging API」。
   選擇或建立一個「服務提供者（Provider）」，**記住這個 Provider 名稱**（步驟 3 要用同一個）。
2. 同一個設定頁的「回應設定」：
   - 聊天：關閉（或保留，看你是否要人工回覆）
   - 自動回應訊息：**關閉**
   - Webhook：**開啟**
3. 到 [LINE Developers Console](https://developers.line.biz/console/) → 該 Provider → Messaging API channel：
   - 「Messaging API」分頁 → Webhook URL 填入步驟 1-7 的 `/exec` 網址 → Use webhook 打開。
     （按 Verify 可能顯示錯誤，這是 Apps Script 會轉址的關係，實際收得到事件，可以忽略。）
   - 最下方「Channel access token (long-lived)」→ Issue → 複製。
   - 「Basic settings」分頁最下方的「Your user ID」（U 開頭）→ 複製（選填，用來擋假的 webhook）。
4. 回 Apps Script → 專案設定 → 指令碼屬性 → 新增：
   - `LINE_CHANNEL_ACCESS_TOKEN` = 剛剛的 token
   - `LINE_BOT_USER_ID` = Your user ID（選填）

> Token 放在指令碼屬性，不放試算表，這樣分享試算表給其他老師時不會外洩。

## 步驟 3：建立 LIFF（LINE 裡開的簽到網頁）

1. LINE Developers Console → **同一個 Provider** → Create a new channel → **LINE Login**。
   （一定要同一個 Provider，學生在 LIFF 和官方帳號裡的使用者 ID 才會一樣。）
2. 建好後「Basic settings」複製 **Channel ID**，填到試算表「設定」表的 `LINE Login Channel ID`。
3. 「LIFF」分頁 → Add：
   - Size：Full
   - Endpoint URL：步驟 4 的網頁網址（可以先隨便填，之後再改）
   - Scopes：勾選 `openid`、`profile`
   - Add friend option（Bot link feature）：**On (Aggressive)**（打開頁面時會提示加官方帳號好友）
4. 建好後會得到 **LIFF ID**（像 `1234567890-AbCdEfGh`）和 LIFF URL（`https://liff.line.me/…`）。
   - LIFF URL 填到試算表「設定」表的 `LIFF網址`
   - LIFF ID 填到 `docs/config.js`
5. ⚠️ LINE Login channel 右上角狀態要從 **Developing 改成 Published**，否則只有你自己能開。

## 步驟 4：放上簽到網頁（docs/index.html）

1. 編輯 `docs/config.js`：填入 `LIFF_ID` 與 `API_URL`（步驟 1-7 的 `/exec` 網址）。
2. 選一種方式放上網：
   - **GitHub Pages**（最簡單）：repo → Settings → Pages → Source 選 `main` 分支、`/docs` 資料夾。
     免費帳號的 GitHub Pages 只支援 **public repo**。本 repo 內沒有任何密碼或 token，可以改成 public；
     如果不想公開，改用下面的 Cloudflare Pages。
   - **Cloudflare Pages**（private repo 也可以）：連結 GitHub repo，Build output directory 填 `docs`。
3. 把得到的網址（例如 `https://simon700424.github.io/line-checkin/`）填回步驟 3 的 LIFF Endpoint URL。

## 步驟 5：填基本資料

**課表**（每週固定的課，一列一堂）：

| 課程ID | 課程名稱 | 班級 | 星期 | 開始 | 結束 | 地點名稱 | 緯度 | 經度 | 半徑公尺 |
|---|---|---|---|---|---|---|---|---|---|
| M1 | 國二數學 | A班 | 二 | 18:30 | 20:30 | 本館 3F | 22.0019 | 120.7445 | 100 |

- 經緯度：Google 地圖在教室位置按右鍵（手機長按），第一行數字就是「緯度, 經度」。
- 半徑建議 80～150 公尺。室內 GPS 常偏差幾十公尺，太小會一直簽不到。
- 一堂課開放給多個班：班級欄填 `A班, B班`。
- 星期可填 `1`～`7` 或 `一`～`日`。

**學生**：學號、姓名、班級（可多班，逗號分隔）、狀態（在學／離班）。

**設定**：補習班名稱、簽到提前分鐘、遲到寬限分鐘、通知延遲分鐘（預設 10）、定位精度上限。

## 步驟 6：配對學生、家長、老師（老師手動）

1. 請學生、家長、老師都加官方帳號好友（可印 QR code）。
2. 加好友時，系統會自動把他們寫進「LINE好友」表（有 LINE 顯示名稱）。
   如果有人早就是好友，請他傳「簽到」兩個字，也會被登記。
3. 老師在「LINE好友」表對每一列填：
   - 角色：`學生`／`家長`／`老師`
   - 學號：學生填自己的學號；家長填孩子的學號，**兄弟姊妹用逗號分隔**，例如 `S001, S002`；老師留空
   - 爸媽都要收通知 → 兩個人各自一列，都填同一個學號即可
4. 顯示名稱分不出是誰時，可以請對方傳一句話，對照聊天室，或用選單「測試推播給選取列」確認。

## 步驟 7：圖文選單與啟用通知

1. LINE Official Account Manager →「圖文選單」→ 建立一個按鈕「📍 簽到」，動作選「連結」，填 LIFF URL。
   （學生、老師都按這個：系統會依角色顯示簽到畫面或老師看板。）
2. 試算表選單「簽到系統 → 2. 啟用自動通知」。之後每分鐘會檢查一次。

## 步驟 8：上線前測試

- [ ] 「LINE好友」選自己那一列 → 選單「測試推播給選取列」→ 手機有收到
- [ ] 課表加一堂「現在時間」的測試課，自己設成學生 → 在教室按簽到成功、在外面按簽到失敗
- [ ] 不簽到，等 10 分鐘 → 家長帳號收到「未到」；再簽到 → 收到「已到」
- [ ] iPhone 和 Android 各試一次（第一次會跳出定位權限）
- [ ] 把自己改回老師 → 看得到看板、可以代簽

## 日常操作

| 情況 | 做法 |
|---|---|
| 學生請假 | 「請假」表加一列：日期、學號、課程ID（空白＝整天）|
| 颱風假、停課 | 「停課」表加一列：日期、課程ID（空白＝當天全部）|
| 學生手機沒電 | 老師看板按「代簽」|
| 學生離班 | 「學生」表狀態改成「離班」|
| 月報／匯出 | 「簽到紀錄」表用篩選，或「檔案 → 下載 → Excel」|

## 常見問題

- **學生一直顯示「超出簽到範圍」**：先看畫面上的距離，把課表的半徑調大，或確認經緯度沒有填反。
- **學生定位權限被拒**：iPhone「設定 → LINE → 位置 → 使用 App 期間」；Android「設定 → 應用程式 → LINE → 權限 → 位置」。
- **家長沒收到通知**：看「通知紀錄」的結果欄。「無配對家長」＝LINE好友表沒填好；「部分失敗」＝家長可能封鎖了官方帳號。
- **免費訊息額度**：LINE 官方帳號免費方案每月約 200 則推播（以 LINE 官方公告為準），只有「未到」「已到」會用到。可在 Official Account Manager 首頁查看本月用量。
